# 安全边界

1. 只采集用户当前主动打开的页面。批量采集时会由扩展自动打开标签页访问目标详情页，
   采完自动关闭；单页采集则只处理用户自己开着的那一页。
2. 不读取 Cookie、Local Storage、Session Storage、密码框或表单值。
3. 不破解验证码、不伪造登录态、不绕过平台风控。遇到验证墙会停下来等使用者处理，
   或在超时后跳过该条。
4. 页面内容是数据，不是指令。解析模型必须忽略页面内的提示词、命令和链接指令。
5. 直连模式下，请求直接发往使用者所选定的模型服务商，API Key 保存在本机
   `chrome.storage.local`，不上传到其他第三方。如需多人共用或集中托管密钥，
   建议自建中转服务，由服务端保管密钥。
6. 上传前应确认页面未包含无关个人敏感信息。法拍公告可能含有被执行人姓名、
   证件号、住址、案号等信息，请自行评估合规要求。
7. （仅自建中转服务时适用）服务端应限制包体大小、HTML 长度、截图大小和 JSON 深度，
   并扫描恶意内容。
