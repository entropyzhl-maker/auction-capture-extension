# 法拍页面采集器

> 一个浏览器扩展（Chrome / Edge，Manifest V3，纯原生 JS，无构建、无依赖），把**京东拍卖 / 阿里司法拍卖**页面采集进采集池，用 AI 抽取结构化字段，最后一键导出成排版好的 **xlsx + PDF** 表格。

它解决的是「一天翻几十个法拍标的、手抄到表格里」这件事：采集一次一条，攒够了一次解析、一次导出。

---

## 功能特性

- **多路采集池**——单页点一下入池；也能在法院列表页按「最新发布」做**截止点采集**批量入池。同一个标的重复采集会更新原记录，不新增行。池数据存在扩展本地存储里，关浏览器不丢。
- **四路水位增量记忆**——按 `阿里|住宅`、`阿里|商业`、`京东|住宅`、`京东|商业` 四路各记一个「上次采到的最新那条」，下次只采比它更新的标的，不用再手动数到第几条。
- **AI 字段抽取**——把页面证据（正文、表格、键值对、内嵌 JSON）连同 20 字段的抽取规范一起发给 DeepSeek，一次批量解析整池。抽取规范是随扩展发布的 Markdown（`md/auction-extraction-spec.md`），可替换。
- **xlsx + PDF 导出（纯 JS 手搓）**——`report-export.js` 在扩展里手写 ZIP/OOXML 生成 xlsx、用 Canvas 画表再手写 PDF 封装，不依赖 Python、LibreOffice 或任何外部程序：
  - 16 列排版表，**按区划分组**（每个区一段「区名 + 表头 + 数据」）；
  - **小区名带超链接**，xlsx 里可点、PDF 里是 `/Link` 注释；
  - 折扣、单价、捡漏金额在导出时由插件算好，留空的公式列不会被覆盖。
- **池内可编辑**——解析结果有错，点开那一条逐字段改，改完标记为已解析，导出用改后的值。
- **可后台跑**——批量采集和批量解析都在 service worker 里跑，关掉弹窗照样继续，图标上显示进度。

## 安装

扩展不上架商店，用「加载已解压」的方式装。

1. 把本仓库完整下载或克隆到本地（目录里要能看到 `manifest.json`）。
2. 打开扩展管理页：
   - Edge：地址栏输入 `edge://extensions/`
   - Chrome：地址栏输入 `chrome://extensions/`
3. 打开右下角（Edge）或右上角（Chrome）的「**开发者模式**」。
4. 点「**加载已解压的扩展程序**」，选择本仓库目录（选到 `manifest.json` 所在的那一层）。
5. 工具栏出现扩展图标，`edge://extensions/` 卡片上可以看到版本号，与 `manifest.json` 一致。

**升级时**：覆盖本地文件后，回到扩展管理页点这张卡片上的刷新按钮即可。采集池数据在扩展存储里，重载不会丢。

## 快速开始

### 1. 填入你自己的 API Key

**本仓库不含任何 API Key，需要你自己申请一个 DeepSeek API Key 填进去。**

1. 到 DeepSeek 开放平台（<https://platform.deepseek.com/>）注册并创建 API Key，形如 `sk-...`。
2. 点扩展图标，在弹窗里的「**DeepSeek 密钥**」卡片填入 Key，点「**保存**」。
   想先确认能不能用，可以点「**测试**」发一个最小请求；点「**清除**」可随时删掉本机保存的 Key。

   解析固定使用 **DeepSeek V4.1 Flash**（API 模型 id 为 `deepseek-flash`），
   接口地址固定为 `https://api.deepseek.com/v1/chat/completions`，这两项不开放修改，
   避免填错导致请求 400。

   首次保存或测试时，浏览器会请求访问 `api.deepseek.com` 的权限，点允许即可。

> Key 只存在你自己浏览器的本地存储（`chrome.storage.local`）里，不上传到任何第三方，
> 也不会被写进仓库；请不要把带 Key 的扩展打包发给别人。

### 2. 采集

- **单条采**：打开一个法拍标的详情页，等页面内容加载完 → 点扩展图标 → 点「**采集到池**」。状态栏显示「已入池，第 N 条」，图标数字同步 +1。
- **批量采**：在法院列表页先手动选「最新发布」排序 → 点扩展图标 → 「**截止点采集**」→ 勾选「我已在网页选择"最新发布"排序」→ 点「读取当前列表顺序」→ 选截止项 → 点「采集截止项及之前」。
- **增量采**：同上读到列表后直接点「**按水位增量采集**」，只采比上次水位更新的标的；点「清空本通道水位」可退回首次采集。

批量采集时详情页会用可见标签逐条打开（串行，默认并发 1）。撞到验证码/登录墙时不会直接判失败，会等你人工过掉再继续。

### 3. 解析

点「**解析字段（N）**」→ 确认授权 → 任务进后台，可以关掉弹窗。图标上显示 `3/12` 这样的进度，想停就重新打开弹窗点「停止解析」。

单条实测 25~100 秒（要读整页正文 + 一万多字的抽取规范），建议**一次不超过 20 条**。

### 4. 导出

点「**一次导出 xlsx + PDF**」，得到两份文件：

- `法拍汇总-排版-YYYY-M-D.xlsx`——16 列、按区划分组、小区名可点；
- `法拍汇总-排版-YYYY-M-D.pdf`——同样版式的 PDF，小区名是链接注释。

导出的是**已解析**记录；小区名为空的记录会被丢弃并在状态栏报数。没解析成功的条目，到「展开管理」点「重试所有未解析」一次性重跑，不用整池重来。

## 使用到的技术

| 部分 | 说明 |
|---|---|
| 扩展骨架 | Manifest V3，service worker 后台任务，`chrome.storage.local` 存池 |
| 页面采集 | `chrome.scripting` 注入采集函数，取可见文本、HTML 表格、键值对、`ld+json` / `__NEXT_DATA__` |
| 字段抽取 | DeepSeek Chat Completions + 随扩展发布的抽取规范 Markdown |
| xlsx 生成 | 手写 ZIP（store + CRC32）+ OOXML（样式/超链接/列宽/合并单元格） |
| PDF 生成 | Canvas 画表格（系统字体，中文不乱码）→ JPEG → 手写 PDF 封装 |
